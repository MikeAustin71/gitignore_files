# gitignore_files



## ***.gitignore*** Files

The purpose of this repository is to store and manage the **`.gitignore`** files used in various project repositories. 

The content of these **`.gitignore`** files have been developed in coordination with guidance for ***JetBrains*** editors. 



## Supporting Go and Multi-Language projects

Currently, two type of **`.gitignore`** files have been created. One is designed for use with virtually all **JetBrains** Editor Projects deploying the **Go Programming Language**. The second is designed for multi-language projects incorporating **Go**, **Rust**, **Python** and **Scripting languages** in a single project.
